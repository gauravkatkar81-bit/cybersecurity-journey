## 🧪 2. Hands-On Lab Walkthroughs & Exercises

### Lab 1: Client-Server Request Inspection
- **Tasks:** Inspect web application response using Mozilla Firefox developer tools.
- **Action:**
  1. Open Mozilla Firefox developer tools using `F12` or `Ctrl + Shift + I`.
  2. Run a GET request and check the Network tab.
  3. Analyze and check details of how the GET request executes, what it returns, and what response we get.
- **Key Takeaway:** Understanding the response header and body is important to get information about the server and web traffic.

---

### Lab 2: Virtualization Setup Overview
- **Tasks:** How to setup lab machines and check how they work.
- **Action:**
  1. Open the lab machine environment to see how it's set up with details like core count, size, and other configurations.
  2. Check if everything is running properly or if there are any errors.
  3. Set up your own machine by giving it a name, size, and core specifications.
  4. Verify all details related to the lab machine, and practice stopping or deleting it when done.
- **Key Takeaway:** Learned how to set up, add, remove, and verify lab machines and assign resources to them.

---

### Lab 3: Cloud Lab Environment
- **Tasks:** Overview of cloud setup and how it works/used.
- **Action:**
  1. Open the cloud environment and check details like regions.
  2. Add and remove cloud instances based on size.
  3. Learned how credits work in the cloud—if the size increases, the credit usage increases too.
  4. Practice stopping or removing the cloud setup when finished.
- **Key Takeaway:** Got a good idea of how the cloud works and how to set up and manage your own cloud instances.
